# **App Name**: MultiFlow Dashboard

## Core Features:

- Pending Demands Display: Display the number of pending demands on the dashboard.
- Completed Tasks Display: Display the number of completed tasks for the week.
- Deadlines Approaching Display: Show the number of deadlines approaching.
- Demands Status Overview: Provide a visual representation of demands status (To Do, In Progress, In Review, Concluded) this month.
- Urgent Tasks List: List urgent tasks with deadlines and project/demand context.
- Demand Creation: Allow the creation of new demands with relevant details.

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) to evoke a sense of calm and clarity, mirroring the original image's color scheme.
- Background color: Very light gray (#F5F7FA), almost white, to provide a clean and spacious feel, allowing the information to stand out.
- Accent color: Pale orange (#FFC8A2) to highlight important elements such as the 'Create Demand' button, contrasting with the blue primary color.
- Body and headline font: 'Inter', sans-serif. For a modern, clean and easily readable look appropriate for dashboards.
- Use simple, outlined icons to represent different sections in the navigation bar (Demands, Projects, Events, Audiovisual).
- Follow a grid-based layout to organize the dashboard elements effectively, ensuring responsiveness and visual balance.
- Implement subtle transitions and animations when data updates or when users interact with elements.
